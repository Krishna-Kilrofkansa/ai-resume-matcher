## Workflow

### Quick Path (30 mins)
1. **Quality Gates** (2 min) → Fix critical issues
2. **Diagnose** (5 min) → Get ATS score + Top 5 Fixes
3. **Rewrite** (20 min) → Rewrite 3-5 weakest bullets
4. **Interview** (5 min) → Quick screening round

### Complete Path (2-3 hours)
1. **Quality Gates** (5 min) → Full 5-gate check
2. **Diagnose** (15 min) → Full audit
3. **Recruit** (20 min) → Market research + gap analysis
4. **Rewrite** (45 min) → Full bullet rewrites + cover letter + LinkedIn
5. **Interview** (60 min) → Full technical + behavioral mock

### Before Job Application
```
1. Run Quality Gates on your resume
   → Fix all 🔴 red flags
2. Diagnose your resume
   → Fix ATS issues
3. Recruit research for the job
   → Add missing keywords
4. Rewrite bullets for this role
   → Use their language from the job posting
5. One quick screening mock
   → Build confidence
6. Submit resume
```

## Quality Gate Quick Reference

| Gate | What It Checks | Severity |
|------|---------------|----------|
| **Repetition** | Duplicate bullets, verb repetition, phrase echoing | 🔴 Exact dupes, 🟡 Semantic dupes |
| **Dates** | Format consistency, gaps, overlaps, chronological order | 🔴 Gaps > 6mo, 🟡 Format mix |
| **Length & Depth** | Page count, bullet count, section balance | 🔴 > 2 pages (entry), 🟡 Imbalance |
| **Spelling** | Typos, tech names, tense, punctuation consistency | 🔴 Misspelled company, 🟡 Mixed tense |
| **Summary** | Presence, length, content quality, keyword density | 🔴 Missing, 🟡 Generic |

## Scoring Explained

### ATS Score (Module 1)
```
100–85: Strong     ✅ Ready to submit
 84–70: Good       ✔️  Fix critical issues first
 69–55: Fair       🟡 Significant work needed
 <55:  Poor        🔴 Major overhaul required
```

### Recruiter Score (Module 2)
```
100–85: Compelling fit for role
 84–70: Solid candidate, minor gaps
 69–55: Has potential, needs gaps closed
 <55:  Significant mismatch, pivot needed
```

### Interview Rating (Module 4)
```
Per answer (out of 10):
 10:    Perfect answer
 8–9:   Strong, minor gaps
 6–7:   Good but needs depth
 4–5:   Weak, missing key details
 1–3:   Very weak, needs major work
```

## Tips & Tricks

### 💡 For Stronger Bullets
- **Find the number**: "Improved latency by 40%", not "made it faster"
- **Name the scope**: "For a team of 5", "for 10K users"
- **Lead with outcome**: "Reduced costs by $2M" before "by switching vendors"
- **Use power verbs**: Engineered, Spearheaded, Architected, Scaled, Reduced, Automated

### 💡 For Better Interview Prep
- **Use STAR format**: Situation → Task → Action → Result
- **Be specific**: "I led the refactor" not "I worked on the refactor"
- **Quantify outcomes**: "Improved from 5s to 1s" not "made it faster"
- **Own the failure**: "I made a mistake in the architecture" > "We had issues"

### 💡 For Passing Quality Gates
- **Repetition**: Use a thesaurus for action verbs — never start 3+ bullets with the same word
- **Dates**: Pick "Mon YYYY" format and stick to it everywhere
- **Length**: 1 page if < 10 years experience, period
- **Spelling**: Triple-check technology names (JavaScript, not Javascript)
- **Summary**: Lead with years + expertise + one big number

## Common Questions

**Q: Can I use this for multiple roles?**
A: Yes! Rerun the Recruiter and Rewriter modules for each target role. The agent maintains your original resume so you can pivot easily.

**Q: How realistic are the mock interviews?**
A: Very. The agent follows real FAANG interview patterns: deep technical dives, behavioral follow-ups, and realistic scoring. Use them to stress-test your answers.

**Q: Do I have to follow the 4-module order?**
A: No. Jump to any module. But Quality Gates → Diagnose → Recruit → Rewrite → Interview is the recommended progression.

**Q: What are Quality Gates?**
A: Five automatic checks that scan your resume for Repetition, Date issues, Length problems, Spelling/consistency errors, and Summary quality before any module runs.
