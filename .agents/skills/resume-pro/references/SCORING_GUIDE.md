# Scoring Guide — All Modules

Detailed scoring rubrics for every scoring system in Resume Pro.

---

## Quality Gate Scoring

### Gate Status Levels

| Status | Meaning | Action Required |
|--------|---------|----------------|
| 🟢 **Pass** | No issues or only minor suggestions | Proceed to modules |
| 🟡 **Warn** | 1–3 non-critical issues found | Fix recommended before submitting |
| 🔴 **Fail** | Critical issues that will hurt your chances | Must fix before proceeding |

### Overall Gate Status

```
5/5 Passed  →  ✅ All clear — proceed with confidence
3–4/5 Passed → ⚠️ Fix warnings before submitting
0–2/5 Passed → 🛑 Critical issues — address before any module
```

## Module 1 — ATS & Recruiter Score (/100)

### Category Breakdown

| Category | Points | What's Evaluated |
|----------|:------:|-----------------|
| Section Completeness | /20 | Are all expected sections present and well-ordered? |
| Bullet Point Quality | /30 | Do bullets follow XYZ? Strong verbs? Metrics? |
| ATS Compatibility | /20 | No tables, standard headings, parseable format? |
| Formatting & Polish | /15 | Consistent tense, dates, spacing, length? |
| Keyword Relevance | /15 | Does the resume contain role-relevant keywords? |

### Score Interpretation

| Range | Grade | Meaning |
|-------|-------|---------|
| 90–100 | A+ | Exceptional — submit with confidence |
| 85–89 | A | Strong — minor tweaks only |
| 80–84 | B+ | Good — 2-3 improvements recommended |
| 70–79 | B | Solid foundation — needs keyword and bullet work |
| 60–69 | C | Fair — significant issues in multiple areas |
| 50–59 | D | Weak — major rewrite needed |
| < 50 | F | Needs complete overhaul |

### Scoring Details

**Section Completeness (/20):**
- Contact info present: +3
- Professional summary: +3
- Work experience (reverse-chron): +4
- Education: +3
- Skills section: +3
- Projects (if < 5 yrs exp): +2
- Certs/Awards (if applicable): +2

**Bullet Point Quality (/30):**
- Starts with strong action verb: +1 per bullet (max 6)
- Contains quantified metric: +1 per bullet (max 6)
- Follows XYZ formula: +1 per bullet (max 6)
- Appropriate length (1-2 lines): +1 per bullet (max 6)
- No duplicates: +6

**ATS Compatibility (/20):**
- No tables/columns: +5
- Standard section headings: +5
- No images/icons: +3
- No header/footer critical info: +4
- Clean font embedding: +3

**Formatting & Polish (/15):**
- Consistent tense: +4
- Consistent date format: +3
- One page (if applicable): +4
- No spelling/grammar errors: +4

**Keyword Relevance (/15):**
- Contains 5+ role-relevant hard skills: +5
- Contains 3+ industry buzzwords: +3
- Action verbs match the field: +4
- Skills section aligns with experience: +3

## Module 2 — Recruiter Score (/100)

### Category Breakdown

| Category | Points | What's Evaluated |
|----------|:------:|-----------------|
| Keyword Match | /25 | Does the resume contain the keywords recruiters search for? |
| Relevance of Experience | /25 | Is the experience directly relevant to the target role? |
| Signal-to-Noise Ratio | /20 | Is every line earning its space? No fluff? |
| Seniority Alignment | /15 | Does the resume signal the right level? |
| First-Impression Impact | /15 | Would a recruiter spend 7+ seconds on this? |

### Score Interpretation

| Range | Recruiter Reaction |
|-------|--------------------|
| 90–100 | "Definitely forwarding to the hiring manager. Strong match." |
| 80–89 | "Solid candidate, scheduling a screen." |
| 70–79 | "Interesting profile. A few gaps but worth a call." |
| 60–69 | "Maybe pile. Depends on other applicants." |
| 50–59 | "Missing too many signals. Would need a referral to move forward." |
| < 50 | "Not a match for this role as presented." |

## Module 4 — Interview Scores

### Per-Answer Rating (/10)

| Score | Label | What It Means |
|:-----:|-------|--------------|
| 10 | Perfect | Comprehensive, quantified, structured, shows leadership |
| 9 | Excellent | Near-perfect, one minor area could be deeper |
| 8 | Strong | Clear structure, good metrics, solid examples |
| 7 | Good | Complete answer but missing depth or specificity |
| 6 | Adequate | Answers the question but generic or surface-level |
| 5 | Borderline | Partially addresses the question, missing key elements |
| 4 | Weak | Vague, no structure, missing STAR components |
| 3 | Poor | Doesn't really answer the question |
| 2 | Very Poor | Off-topic or shows misunderstanding |
| 1 | No Answer | Declined to answer or completely irrelevant |

### Final Hiring Decision

| Decision | Score Range | Meaning |
|----------|:----------:|---------|
| **Strong Hire** | 8.5–10 avg | Exceptional candidate, would compete for them |
| **Hire** | 7.0–8.4 avg | Solid candidate, confident in their ability |
| **No Hire** | 5.0–6.9 avg | Not ready for this level; needs preparation |
| **Strong No Hire** | < 5.0 avg | Significant gaps in fundamental areas |

### Debrief Components

The final debrief must include:
1. **Overall score** — weighted average of all question scores
2. **Per-question breakdown** — score + topic for each question
3. **Strengths** — 2-3 specific things done well (with examples from answers)
4. **Areas to improve** — 2-3 specific weaknesses with actionable advice
5. **Answers to revisit** — For the 2-3 weakest answers, provide a model answer
6. **Hiring decision** — One of the four levels above with a 2-sentence justification
