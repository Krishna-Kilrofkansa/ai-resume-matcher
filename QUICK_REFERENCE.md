# Resume Pro — Quick Reference

## What to Ask

### Module 1: Diagnoser (ATS Scan)
```
"Review my resume for ATS issues"
"Give me an ATS compatibility score"
"What are the top 5 things I need to fix in my resume?"
"Check my resume's formatting and structure"
```

### Module 2: Recruiter (Job Market Gap Analysis)
```
"I'm targeting [role title] at [company type]. What am I missing?"
"What skills should a Senior Backend Engineer have?"
"Do a gap analysis of my resume vs. real job postings"
"Analyze my resume as a recruiter would"
```

### Module 3: Rewriter (Bullet Point Optimization)
```
"Rewrite my bullets using the XYZ formula"
"Help me rewrite my resume with impact metrics"
"Write a cover letter for this job posting: [paste or link]"
"Rewrite my LinkedIn About section"
"Write a cold outreach email to a recruiter"
```

### Module 4: Hiring Manager (Mock Interview)
```
"Mock interview me for a [Round Type] at [Company]"
"Conduct a technical interview for a backend engineering role"
"Do a behavioral interview for a product manager position"
"Run a full onsite simulation (screening → technical → behavioral)"
```

## Workflow

### Quick Path (30 mins)
1. **Diagnose** (5 min) → Get ATS score + Top 5 Fixes
2. **Rewrite** (20 min) → Rewrite 3-5 weakest bullets
3. **Interview** (5 min) → Quick screening round

### Complete Path (2-3 hours)
1. **Diagnose** (15 min) → Full audit
2. **Recruit** (20 min) → Market research + gap analysis
3. **Rewrite** (45 min) → Full bullet rewrites + cover letter + LinkedIn
4. **Interview** (60 min) → Full technical + behavioral mock

### Before Job Application
```
1. Diagnose your resume
   → Fix all 🔴 red flags
2. Recruit research for the job
   → Add missing keywords
3. Rewrite bullets for this role
   → Use their language from the job posting
4. One quick screening mock
   → Build confidence
5. Submit resume
```

## Scoring Explained

### ATS Score (Module 1)
```
100–85: Strong     ✅ Ready to submit
 84–70: Good       ✔️  Fix critical issues first
 69–55: Fair       🟡 Significant work needed
 <55:  Poor        🔴 Major overhaul required
```

### Recruiter Score (Module 2)
```
100–85: Compelling fit for role
 84–70: Solid candidate, minor gaps
 69–55: Has potential, needs gaps closed
 <55:  Significant mismatch, pivot needed
```

### Interview Rating (Module 4)
```
Per answer (out of 10):
 10:    Perfect answer
 8–9:   Strong, minor gaps
 6–7:   Good but needs depth
 4–5:   Weak, missing key details
 1–3:   Very weak, needs major work
```

## Tips & Tricks

### 💡 For Stronger Bullets
- **Find the number**: "Improved latency by 40%", not "made it faster"
- **Name the scope**: "For a team of 5", "for 10K users"
- **Lead with outcome**: "Reduced costs by $2M" before "by switching vendors"
- **Use power verbs**: Engineered, Spearheaded, Architected, Scaled, Reduced, Automated

### 💡 For Better Interview Prep
- **Use STAR format**: Situation → Task → Action → Result
- **Be specific**: "I led the refactor" not "I worked on the refactor"
- **Quantify outcomes**: "Improved from 5s to 1s" not "made it faster"
- **Own the failure**: "I made a mistake in the architecture" > "We had issues"

### 💡 For Faster Results
- Have your resume ready before asking
- Be specific about your target role (company, seniority level)
- Ask for one module at a time if in a hurry
- Save rewritten bullets to a document for later use

## Common Questions

**Q: Can I use this for multiple roles?**
A: Yes! Rerun the Recruiter and Rewriter modules for each target role. The agent maintains your original resume so you can pivot easily.

**Q: How realistic are the mock interviews?**
A: Very. The agent follows real FAANG interview patterns: deep technical dives, behavioral follow-ups, and realistic scoring. Use them to stress-test your answers.

**Q: Do I have to follow the 4-module order?**
A: No. Jump to any module. But Diagnose → Recruit → Rewrite → Interview is the recommended progression.

**Q: Can I edit the skill?**
A: Yes! Update SKILL.md and the agent will load the new version on next use. You can add:
  - Custom question banks for interviews
  - Company-specific resume templates
  - Interview round scripts
